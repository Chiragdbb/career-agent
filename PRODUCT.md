# Waypoint — Product Context

## What it is
AI-assisted career workspace for discovering jobs, preparing truthful application materials, coordinating outreach, and tracking the hiring pipeline — with **human approval before any outbound action**.

## Audience
Ambitious job seekers and senior ICs who want speed without losing control or integrity.

## Non-negotiables
- Never fabricate experience, skills, employers, dates, or metrics.
- Never mark an application SUBMITTED without evidence.
- Never send email without explicit user approval (or an explicit automation rule).
- PostgreSQL is system of record; long work runs in workers.

## Primary user journeys
1. Sign up → set preferences → upload résumé → discover jobs → triage → apply (approve) → track.
2. Daily: Approvals queue → Opportunities → Conversations → Interviews.
3. Settings/profile for account; Documents for résumé versions.

## Surfaces
- Marketing (`/`): Persuade — trial signup.
- App shell: Operate — task-first cockpit.
